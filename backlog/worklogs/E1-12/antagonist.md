**Verdict:** VIOLATIONS FOUND

The owner's two rulings (the API is the source and KOV is not consulted first; only goal set G, with Z and V named as skipped) are recorded faithfully and the code honours them. Every figure the amendment writes into the constitution checks out against my own fetch of KOV's live API (5,654 refs, 0 unresolved, no goal with two refs, 992/998 reachable through G, `6-7.1.6` only through Z, and `K-1.2.6`, `4-2.2.23`, `6-2.2.3`, `6-6.2.5`, `6-6.3.9` through no goal). The violations are elsewhere: a test regression the record misses, a review report that can say something false, a converter guard with holes that this change's own backlog routes E1-21 into, and dependent text the amendment did not update.

1. **[MAJOR] An existing, non-Postgres test now fails, and the DI line will not fix it** (Art. X.1, XIII). `CurriculumbeheerAutorisatieTests.cs:54` asserts `Assert.Equal(2, endpoints.Count)` over every `api/opstap-import*` route; MVC discovers the new controller regardless of DI, so it is 4. Fix: raise to 4, naming the routes; re-run the whole project; correct worklog and backlog.
2. **[MAJOR] The review report calls a refused row "no longer in the source"** (Art. III.4; conditional-copy rule; Art. II.3). `MinimumdoelImportService.cs:66,99-103,115,125-128` and the `Verdwenen` doc: `inkomendeRefs` holds only cleanly mapped rows, so a previously imported ref that the mapping now refuses (unknown markup, missing `$$expanded`, expired) lands in `Verdwenen` and directie reads that the decree dropped it. No test covers it. Fix: compute `Verdwenen` only against refs the source did not name at all; report refused-but-present refs in their own bucket with a sentence that says only what that branch guarantees; add a test.
3. **[MAJOR] The converter's guard admits text-changing markup, and the backlog sends E1-21 into it** (Art. III.1). `OpstapHtml.cs:34-38,54,56,110,113` and the doc claim at `:26-28`; `backlog/E1-curriculum-content.md:317`. (a) `sup`/`sub` are whitelisted then stripped: G goal `2.1.GL3.10` has `10<sup>2</sup>=10x10= 100` → `102=10x10= 100`. (b) A raw `<` not followed by a letter is invisible to `OnbekendeTags` but consumed by `Tag()`: G goal `2.1.GL1.2` `=, ≠, <, > (tussen getallen)` → `=, ≠, (tussen getallen)`; `2.3.GL2.48`, `2.3.GL3.55` carry `(< 1 week)`. (c) alt-less `<img>` imports as `[afbeelding]`; a single-quoted `href` loses its address; `<ol>` numbering becomes `- `. Verified safe today for the 998 minimumdoelen (tag set exactly `p ul li br strong em a img math mfrac mn`, 0 bare `<`, 0 alt-less images). Fix: take `sup`/`sub` out or convert them; refuse any span `Tag()` would remove that is not a well-formed known tag, or escape a bare `<` first; refuse alt-less images and non-double-quoted attributes; add those two goals as test inputs; warn E1-21.
