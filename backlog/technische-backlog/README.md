# Technische backlog (TB)

Tickets voor verbeteringen die de eigenaar zelf start en die nog geen functioneel ticket of story hebben. Een
agent-sessie maakt ze aan op de branch van het werk, **voor** er een bestand verandert (skill `ticket-uitvoeren`).
Structuur, statussen en het bord: [`../TICKETS.md`](../TICKETS.md).

Dit bestand is uitleg, geen ticket: het bord en `tickets.mjs` slaan `README.md` over.
